# 郭家乐的个人学术网站

## 🌟 项目简介

这是郭家乐（Jiale Guo）的个人学术网站，展示地理空间数据科学、城市计算、遥感应用等领域的研究成果、学习笔记和项目经验。网站采用现代化的响应式设计，支持中英文双语切换，为学术交流和知识分享提供了一个专业的平台。

## 🎯 网站特色

### 📚 **Books & Notes** - 学术笔记与知识框架
- **地理空间数据科学手册** - 系统性的学习笔记和实践经验
- **GIS学习笔记与知识框架** - 米兰理工大学GIS课程详细笔记
- **SHUD水文模拟笔记** - 水文建模理论与实践应用
- **街景地理大数据分析框架** - 街景数据处理方法论
- **基于社交媒体数据的城市感知计算** - NLP与城市计算结合应用

### 🔬 **Research & Projects** - 研究项目
- **30DayMapChallenge** - 数据可视化挑战项目
- **空气污染暴露分析** - 环境数据空间分析
- **情感分析应用** - 社交媒体文本挖掘
- **本科毕业论文** - 江淮地区干旱分析研究

### 📊 **Presentations** - 学术演示
- 会议报告、课程演示、研讨会分享
- 支持在线查看和PDF下载

### 🌍 **Interactive Features** - 交互功能
- **Mermaid图表支持** - 知识框架图自动渲染
- **响应式设计** - 支持各种设备屏幕
- **双语切换** - 中英文无缝切换
- **在线阅读器** - 支持Markdown文档在线浏览

### 本地开发
```bash
# 克隆项目
git clone https://github.com/GuojialeGeographer/guojialegeographer.github.io.git

# 进入项目目录
cd guojialegeographer.github.io

# 启动本地服务器
python3 -m http.server 8000

# 在浏览器中访问
# http://localhost:8000
```

## 🛠️ 技术栈

- **前端框架**: Bootstrap 4.6.0
- **图表库**: Mermaid.js (支持流程图、序列图等)
- **文档处理**: Marked.js (Markdown解析)
- **图标库**: Font Awesome 6.5.1
- **样式**: 自定义CSS + 响应式设计
- **托管**: GitHub Pages
- **版本控制**: Git
